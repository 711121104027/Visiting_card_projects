# Freedom Financial Services — Digital Visiting Card

## Step 1 — Splash Screen

This version contains only the premium branded splash screen for the QR landing experience.

### Brand
- Company: Freedom Financial Services
- Tagline: Unleashing Your Real Freedom
- Primary brand color: `#00A885`

### Splash behavior
- Full-screen mobile-first branded background
- White primary logo
- Premium logo reveal using Framer Motion
- Soft ambient glow and orbital rings
- Subtle grain texture
- Animated loading line
- Reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
